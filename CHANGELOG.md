# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-11-09

### Added

- Browser-only QR editor for text, URLs, Wi-Fi, vCard contacts, email, phone and SMS.
- Custom body and finder shapes, solid and gradient fills, transparent backgrounds, embedded logos, quiet zones and error correction controls.
- Live SVG preview, local PNG/SVG downloads, scan decoding and contrast diagnostics.
- CSV, TSV and plain-text bulk input with row diagnostics, custom filenames, ZIP export, progress and cancellation.
- Worker-assisted PNG exports with a main-thread fallback.
- Validated design preferences that persist across reloads without retaining QR payloads or bulk rows.
- Responsive light/dark themes, keyboard navigation, accessibility checks and offline app caching.
- Automated verification, SSH deployment, Caddy security headers and an operational deployment runbook.
- Project documentation, reproducible light/dark screenshots and contribution templates.
